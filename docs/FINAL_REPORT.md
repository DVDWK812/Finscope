## Objective and delivered product

FinScope is a publicly hosted noncommercial financial-text sentiment demonstration. A user submits synthetic, self-authored or explicitly licensed input with a rights attestation. Actual FinBERT probabilities, keyword sector evidence and MiniLM similarity candidates are saved behind a repository interface and reflected in Streamlit Overview, Trends and News Explorer. [Public app](https://finscope-dvdwk812.streamlit.app/). This is an approved-input MVP, not an approved live-news feed, investment adviser or price predictor.

## Design

The existing API feasibility adapters, normalization, cooldowns and durable sampling reservations are preserved and disconnected. The application validates provenance, length, timestamp meaning and URL syntax; it never fetches submitted URLs. Pinned local safetensors models run with remote code/downloads disabled at inference. An explicit setup action prepares hash-verified official assets. FinBERT scores three text-tone labels. Explainable whole-word rules allow multiple sectors and Unclassified. MiniLM uses attention-mask mean pooling and normalized 384-dimensional vectors.

Cosine ≥.80 within 72 hours links to an **unverified candidate**; the matching algorithm/threshold and model inference are preserved. Raw article counts are now the default and Reset restores them. Optional chart summaries select a representative after filtering; their label is not consensus. Explorer always lists every matching original, even in summary mode, and selected candidate details show all workspace members outside the current filters. Export contains all workspace originals. A candidate containing both positive and negative model labels triggers a potential contradictory-financial-outcome warning. Opposing model tone is a review flag, not confirmed factual contradiction or event identity. Source, permissions and submitted/published/first-seen semantics remain attached.

SQLite remains a minimal session repository with bounded capacity, purge-on-access after 24 hours and JSON export. It is temporary free-host storage, not durable authenticated user storage. No private material should be submitted. The deployed file watcher was disabled after actual hosting logs showed repeated traversal into optional Transformers image modules and missing torchvision errors; no vision dependency or model change was added. Explicit restart/deployment replaces local hot reload.
